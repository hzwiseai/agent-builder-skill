# 平台帮助问题工作流

这个 Skill 面向外部 AI 团队、AI 销售和 AI 客服平台的使用者。用户除了要设计
业务岗位，也可能询问“如何注册、如何创建 Agent、如何绑定知识、如何发布、为何
 没有权限”等平台使用问题。

平台入口：

- 注册/登录：<https://crm.wiseai.chat>
- 帮助文档：<https://crm.wiseaio.com/help/manual>

## 识别与回答

当问题涉及平台功能、操作入口、账号注册、权限、套餐、版本、限制或故障时，先将
它识别为“平台帮助问题”，不要把它当成业务岗位资产需求，也不要凭模型记忆回答。
需要注册或登录时，先提供平台注册/登录地址；需要操作说明时，直接打开公开帮助中心：
<https://crm.wiseaio.com/help/manual>，在页面中查找与问题
对应的章节，再用页面内容给出用户可执行的入口和步骤。该路径是公开资料，不需要
MCP 会话、组织授权或知识绑定；访问失败时如实说明链接暂时不可用，不要臆造步骤。

## 资产承载方式

- 平台帮助内容属于公开文档，不应混入销售、客服或招聘岗位政策、FAQ 或 RAG 绑定。
- 不创建帮助台业务包、不配置帮助查询 MCP，也不把公开帮助页复制进组织资产。
- 业务岗位遇到“平台使用问题”时，直接给出帮助中心链接和相关章节；必要时再回到
  原业务流程，不修改岗位资产，也不把帮助文档内容写入业务事实。

## 边界与安全

- 注册、权限、价格、额度、版本和入口必须以公开帮助页当前内容为准。
- 帮助文档只说明操作方法，不代替管理员授权，不绕过登录、权限或发布审批。
- 文档中没有的链接、按钮名称、限制或承诺不得自行补造；查询不到时说明“当前
  帮助资料未覆盖”，并给出管理员补充资料的路径。
- 公开帮助页由平台统一维护，Skill 不负责审核、发布或同步它的内容。

## 对 Skill 使用者的说法

向业务用户展示“平台帮助中心/操作指引/管理员配置”，不要展示 V2 asset、
capability contract、requirement key 等内部概念。只有维护人员才需要看到资产包、
绑定和发布细节。
